# Practical File — Object Oriented Programming Using Java
## COER University | MCA III Semester | Lab Sheet-08

### Aim
To implement JavaBeans, bean introspection and property-change events, and demonstrate Java networking using TCP, UDP, URL/URLConnection, and multithreading.

### Software Requirements
- Java Development Kit (JDK) 17+
- Command Prompt / Terminal or an IDE such as IntelliJ IDEA, Eclipse, or VS Code

### Experiments
The `src` folder contains separate Java programs for all 20 exercises. The mapping and execution commands are provided in `README.md`.

### Result
All 20 exercises are provided as independent Java source files. Networking programs should be tested using separate terminal windows, starting the server before the client.

### Learning Outcomes
- Create JavaBeans with standard, read-only, and write-only properties.
- Implement serialization and property-change notification.
- Inspect bean properties using Java Introspector.
- Use InetAddress, TCP sockets, UDP datagrams, URL and URLConnection.
- Build a basic multithreaded TCP server.

### Important
Network examples require appropriate local network permissions. WebReader and FileDownloader require internet access. The example download URL may not host the requested sample file.
