# Practical File — Object Oriented Programming Using Java
## COER University | MCA203P | Lab Sheet 09

### Aim
To understand and implement Java Collection Framework interfaces and classes, including List, Set, Queue, ArrayList, LinkedList, HashSet, LinkedHashSet, TreeSet, PriorityQueue, Iterator, and Comparator.

### Software Requirements
- JDK 8 or later (JDK 17 recommended)
- Java IDE or terminal

### Experiments
This practical set contains 30 independent programs. Each question is implemented in a separate Java source file under `src/`. Refer to README.md for the complete question-to-file mapping and execution commands.

### Result
The programs demonstrate collection creation, insertion, deletion, retrieval, traversal, sorting, duplicate handling, conversion between collection types, and clearing collections.

### Key Learning Outcomes
- Use List implementations such as ArrayList and LinkedList.
- Understand uniqueness and ordering behavior in HashSet, LinkedHashSet, and TreeSet.
- Perform queue operations using Queue and PriorityQueue.
- Iterate over collections and custom objects using Iterator.
- Sort custom objects using Comparator.
- Convert between List and Set.

### Conclusion
The exercises illustrate how to select an appropriate collection based on ordering, uniqueness, and processing requirements.
