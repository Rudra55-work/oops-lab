# Java ML Project Viva Questions

1. **Why Java for this project?** Java provides object-oriented programming, portability, and a mature ecosystem for desktop applications and ML libraries.
2. **What is Weka?** An open-source Java machine-learning toolkit for data preprocessing, classification, clustering, and evaluation.
3. **What is ARFF?** Attribute-Relation File Format, used by Weka to represent datasets and their attributes.
4. **What is classification?** Predicting a discrete class label from input features.
5. **What is binary classification?** Classification into two classes, such as approved/not approved.
6. **What is multi-class classification?** Classification among more than two possible labels.
7. **What is Logistic Regression?** A statistical classification algorithm that estimates class probabilities.
8. **What is J48?** Weka's implementation of a C4.5-style decision tree.
9. **What is Random Forest?** An ensemble of decision trees whose predictions are combined.
10. **What is KNN / IBk?** A classifier that predicts using the labels of nearby training instances.
11. **Why split training and testing data?** To estimate performance on examples not used for fitting.
12. **What is accuracy?** The percentage of correctly classified test examples.
13. **What is F1-score?** The harmonic mean of precision and recall.
14. **What is a confusion matrix?** A table showing actual versus predicted class counts.
15. **Why serialize a model?** To save a trained classifier and reload it without retraining.
16. **What is Swing?** Java's GUI toolkit for desktop applications.
17. **What is Maven?** A build and dependency management tool for Java projects.
18. **Why use synthetic data?** To provide reproducible sample data without using real personal records.
19. **Can the disease application diagnose a patient?** No. It is a non-clinical synthetic-data classroom demonstration.
20. **What are future improvements?** Use approved real datasets, cross-validation, hyperparameter tuning, fairness checks, explainability, and expert validation.
